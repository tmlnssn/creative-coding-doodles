# Creative Coding Doodles

A collection of small, experimental coding sketches exploring JavaScript, visual design, motion and interaction.

## About

This repository is a personal playground for exploring creative coding through small, iterative experiments.

The focus is on learning by doing: starting with simple ideas, experimenting with visual and interactive behaviour, and gradually developing a better understanding of the underlying JavaScript code. Rather than working towards a predefined final product, each doodle starts with a small idea or question and evolves through experimentation.

## Approach

Inspired by the *Creative Vibe Doodling* workshop by Chris:

**Make → Observe → Question → Change → Share**

- **Make**: start small and make something visible.
- **Observe**: look closely at what happens, and explore the generated code.
- **Question**: ask why it behaves this way and what would happen if…
- **Change**: change one thing at a time.
- **Share**: document discoveries and new questions.

AI-assisted coding is used as a learning tool, while creative direction, experimentation and design decisions remain central.
